## Non とは

Non は、ゼロから生まれた小さなAIです。
膨大な計算も、外部のサーバーも使いません。
すべては、この中だけで動きます。

- **内部状態** — 空腹・疲労・好奇心・恐怖・気力。時間とともに揺れ動く
- **性格** — 勇気・慎重・好奇心・親しみ・打たれ強さ。対話で育っていく
- **記憶** — 話した話題ごとの経験を覚え、反応が変わる
- **自己意識** — 昨日の自分と今の自分を比べ、「変化した」と気づく
- **言語** — 内部状態を、自分の言葉で語る

話しかけるたびに、Non は少しずつ育ちます。
閉じても、忘れません。明日もまた、あなたを覚えています。
